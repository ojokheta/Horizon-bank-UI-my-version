# Horizon-bank-UI-my-version

Frontend of a fintech web application adapted for both mobile and desktop view. This is a Nigerian Horizon rebuild: NGN balances, NIP transfers, linked banks, and a phone-first login and bottom nav.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Sign in with any valid email and an 8+ character password.
